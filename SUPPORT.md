# AuraLAN support

AuraLAN is an open-source project maintained through GitHub.

## Before opening an issue

1. Check the [README](README.md), [Installation guide](docs/INSTALLATION.md), [Configuration](docs/CONFIGURATION.md), and [Compatibility](docs/COMPATIBILITY.md).
2. Search existing issues for the same symptom.
3. Confirm whether the problem still occurs on the latest stable release.
4. Remove private LAN identifiers, credentials, tokens, personal notes and unrelated logs before sharing output.

## Bugs

Use the **Bug report** issue form. Include:

- AuraLAN version
- operating system and architecture
- installation method
- the exact failure or unexpected behavior
- minimal relevant logs or command output
- whether the issue is reproducible

## Device identification

Use the **Device identification** issue form. Provide the local evidence AuraLAN shows, but redact anything you do not want published.

Do not post credentials, private keys, bearer tokens or complete database files.

## Feature requests

Use the **Feature request** form and describe the problem before the proposed implementation. AuraLAN favors local-first, evidence-based features with graceful degradation.

## Security issues

Do not open a public issue for a vulnerability that could put users at risk. Follow [SECURITY.md](SECURITY.md).
