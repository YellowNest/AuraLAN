# Support

AuraLAN is pre-1.0 software. Bug reports and focused feature requests belong in GitHub Issues.

Before opening an issue:

1. update to the latest supported revision;
2. run `python3 scripts/validate-release.py`;
3. check the service health endpoint;
4. include your Linux distribution, architecture, AuraLAN version and relevant optional providers.

Never post credentials, private keys, tokens, real SSIDs, unredacted MAC addresses, household hostnames, public IP addresses, packet captures or private configuration.

For installation and provider requirements, see [Installation](docs/INSTALLATION.md), [Configuration](docs/CONFIGURATION.md), and [Compatibility](docs/COMPATIBILITY.md).
