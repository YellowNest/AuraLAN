# Code of Conduct

## Our standard

AuraLAN aims to be a technical community where people can contribute, ask questions and disagree about implementation without personal hostility.

Expected behavior includes:

- discussing code, evidence and tradeoffs rather than attacking people
- giving actionable review feedback
- assuming ordinary mistakes are mistakes
- respecting different experience levels
- keeping issue and pull-request discussions relevant to the project

Unacceptable behavior includes harassment, threats, discriminatory abuse, doxxing, sexualized harassment, deliberate disruption, or publishing another person's private information without permission.

## Enforcement

Project maintainers may edit, hide, lock or remove contributions that violate these standards and may restrict participation when necessary to protect the community.

For conduct concerns that should not be handled publicly, contact the maintainer through the private contact options available on the maintainer's GitHub profile.

## Scope

This code of conduct applies to AuraLAN project spaces and to public interactions where someone is representing the AuraLAN project.
